# How to Run

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
python -m venv venv
```

Activate venv:

- **PowerShell:** `.\venv\Scripts\Activate.ps1`
- **CMD:** `.\venv\Scripts\activate.bat`
- **Linux/Mac:** `source venv/bin/activate`

```bash
pip install -r requirements.txt
python app.py
```
